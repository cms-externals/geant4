
\page README_HowToNavigate How to navigate in the examples documentation 

The examples documentation is structured into two main components: "global" documentation and "standalone" documentations.

## Global documentation

The global documentation starts from the **Main Page** and contains all examples README pages that follow the
examples category structure. These README pages do not contain links to the examples source code documentation.

## Standalone documentations

The standalone documentations start from the **Examples** menu and includes the links to all examples
detailed documentation including the examples README pages hyperlinked with the source code documentation,
and the standard Doxygen menu with the "Namespaces', Classes" and "Files" lists.
