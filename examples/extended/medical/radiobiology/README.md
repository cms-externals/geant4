\page Exampleradiobiology Example radiobiology

\author L Pandola, D Chiappara, GAP Cirrone, G Petringa, A Sciuto, S Fattori; INFN LNS (Italy)

Radiobiology is a Geant4 application for dosimetric and radiobiological studies
with proton and ion beams. It scores absorbed dose, particle-entry counts,
linear energy transfer (LET), relative biological effectiveness (RBE), and cell
survival in a voxelized target.

## 1. Geometry

The geometry consists of an outer air world and an inner material container.
Only the inner container is voxelized and made sensitive, so the source can be
positioned outside the scoring volume.

`macro/defaultMacro.mac` configures:

- an 8 x 8 x 8 cm air world;
- a 4 x 4 x 4 cm water container;
- 1 x 40 x 40 mm voxels, giving 40 slices along the beam direction;
- a point-like proton source 1 cm upstream of the container surface.

Voxel dimensions are adjusted to divide the container into an integer number
of replicas. A requested width larger than the container produces one voxel
along that axis. The `/voxels/update` command rebuilds the complete detector
geometry after container, world, or voxel dimensions are changed in the idle
state.

## 2. Physics

The example uses `G4EmStandardPhysics_option4` for electromagnetic interactions
and provides the `HADRONTHERAPY_1` and `HADRONTHERAPY_2` configurations for
hadronic interactions. Production cuts can be configured using standard Geant4
commands, for example:

```
/run/setCutForAGivenParticle e- 0.1 mm
/run/setCutForAGivenParticle e+ 0.1 mm
/run/setCutForAGivenParticle proton 0.1 mm
```

The default macro runs 100,000 protons with a Gaussian energy distribution
centered at 58 MeV and a standard deviation of 0.65 MeV.

## 3. Dose

`dose.out` contains the voxel indexes followed by total, primary-track, and
secondary-track absorbed dose in gray. Additional columns contain the dose from
each secondary particle species observed during the run. Here, a primary track
has `ParentID == 0`; every descendant is classified as secondary.

## 4. Particle-entry counts

`beamFluence.out` contains the number of unique tracks visiting each voxel,
separated into total, primary, secondary, and particle-species columns. A track
created inside a voxel is included, and a track that later re-enters the same
voxel is not counted twice.

The stored values are particle-entry counts and are not normalized by area.
They can be used for per-slice beam survival and composition profiles, but they
are not a differential fluence estimator.

Particle-entry counting is demonstrated by `macro/test.mac`. It can be enabled
in another macro with:

```
/beamFluence/calculate true
/beamFluence/fileName beamFluence.out
```

The other settings are available under `/beamFluence/`.

## 5. LET

`LET.out` contains dose-averaged and track-averaged LET for each voxel. The first
three columns are the voxel indexes, followed by total dose-averaged LET (LDT),
total track-averaged LET (LTT), and the corresponding values for each ion.

## 6. RBE and survival

The RBE calculation combines Geant4 energy-deposition data with lookup tables
generated by the Survival toolkit. The kinetic energy and LET of primary and
secondary ions are used to interpolate the alpha and beta parameters for the
selected cell line.

The output files are `RadioBio_AlphaAndBeta.out` and `RadioBio_RBE.out`. The
latter contains physical dose, the logarithm of the survival fraction, survival
fraction, biological dose, and RBE for each voxel.

The method is described in G. Petringa et al., *Physica Medica* 58 (2019)
72-80, and L. Manganaro et al., *Physics in Medicine & Biology* 63 (2018).

## 7. Running and testing

Run the default calculation from the build directory with:

```
./radiobiology macro/defaultMacro.mac
```

Starting the executable without arguments opens an interactive session and
executes `macro/visualize.mac`. The short regression macro exercises the custom
commands, geometry reinitialization, and every scorer:

```
./radiobiology macro/test.mac
```

## 8. Analysis scripts

`analysis/plot_dose.py` and `analysis/plot_beam_fluence.py` provide interactive
profiles along the beam direction. They require Python 3, pandas, and
Matplotlib. Their input paths and selected transverse voxel indexes can be
changed in the settings section at the top of each script.
